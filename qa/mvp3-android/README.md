# Проверка Android-кандидата MVP3

Подготовлено для ветки `qa/mvp3-android-sqlite` в `bmv2002qq-star/Glucopapa`. Основа — `source-P1-P5.zip` с SHA-256 `10c3c8fb24faf0f07b658ea087770d906f4921801bd6422915b4c084f981ebfb`. Каталог `android-mvp3/` содержит 119 файлов Android-проекта. В `MainActivity.java` учтены системные отступы Android 15, выявленные на эмуляторе. 108 файлов WebView совпадают с архивом. `android-source.sha256` проверяет текущий Android-кандидат побайтно.

Workflow запускается только при push в названную ветку. На выделенном runner проверяется KVM, собирается debug APK и создаётся чистый Android 15 AVD. Сценарий использует обычный интерфейс, подтверждает отсутствие записи без флажка, затем подтверждает одну синтетическую запись, останавливает процесс и сверяет сохранённый снимок SQLite после запуска. В отчёт Actions попадают результат, системные логи, XML интерфейса и скриншоты синтетического теста. APK и копии базы для отчёта о запуске не выгружаются.

Локально проверены SHA файлов, синтаксис Python, Bash и структура workflow. Полный результат появляется после реального запуска на runner.
