РинФаст — исследование действия v0.3.1

Инсулин аспарт, не «РинФаст Ник» · независимый офлайн-стенд

Версия 0.3.1 · исправлены графики
Не использовать для назначения инсулина, еды или лечения гипогликемии. Все дозы на экране вымышленные. Графики показывают условную долю сахароснижающего действия по OpenAPS. Они не измеряют инсулин в крови и не предсказывают сахар ребёнка. При подозрении на ошибочную дозу требуется срочная медицинская оценка.

1. Параметры исследования

По умолчанию — опубликованная кривая OpenAPS для обычного инсулина аспарт: пик модельной активности 75 минут, DIA 300 минут.

Длительность более 300 минут здесь используется только для сравнения чувствительности модели, а не как подтверждённая продолжительность действия конкретной инъекции.

2. Условный журнал инъекций

Значения не связаны с реальным дневником. Время задаётся относительно момента расчёта (0 = сейчас).

Для расчёта требуются только подтверждённые фактические введения. Запланированная инъекция блокирует результат, а не считается введённой.

3. Данные производителя

Начало наблюдаемого действия 10–20 мин
Максимальный эффект 1–3 часа
Продолжительность 3–5 часов

Внутри математической кривой активность плавно возрастает с момента укола. Диапазон начала по инструкции не превращаем в искусственную ступеньку на 10-й минуте.

6. Насколько результат зависит от 5 или 6 часов?

Один и тот же журнал, один и тот же пик; меняем только DIA. Разница показывает чувствительность алгоритма, не индивидуальную биологическую погрешность.
