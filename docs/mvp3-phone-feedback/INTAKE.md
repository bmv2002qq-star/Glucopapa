Скриншоты и пример с телефона используются как материалы владельца для диагностики. Публичные тесты создают собственные синтетические пакеты, в том числе эквивалентную форму времени со смещением +0300. Числовое время примера и дата со смещением совпадают. Доступность локального Web Service на телефоне подтверждена сообщением владельца. Результат исправленного приложения проверяется отдельно.

## Воспроизведение

```bash
node --test qa/mvp3-feedback/web-live.test.cjs
python3 qa/mvp3-feedback/browser.py --output qa-output/phone-feedback
node qa/mvp3-feedback/backup-v015.cjs /path/to/0.3.15/assets/www
node qa/mvp3-pilot/replay-90d.cjs
```

Тесты Android используют обычный APK с изолированной синтетической базой и отдельный пакет fixture для расширенной нагрузки. Исходный CGM-контракт сверён с Web Service и ContentProvider опубликованного xDrip+. Рабочие ядра и защищённые представления сравниваются по перечню SHA-256. [Аудит реализации xDrip+](../mvp3-unified/XDRIP_FOLLOWER_AUDIT.md)
