# Точка продолжения 0.3.17-qa

## До следующей сборки

- Воспроизвести системный Back на API 36 с трассировкой фокуса и источника событий. Повторить системную кнопку и жест.
- Подключить поддерживаемый образ API 31 с актуальным WebView для дерева доступности. Сохранить подтверждённый контроль касаний на нынешнем образе.
- Для обновления поверх установленной V2 использовать ранее сохранённый ключ подписи. Для двух проверенных debug APK подходит перенос через резервную копию. Формат проверен на синтетических фактах.
- Для включения дополнительных численных моделей нужны утверждённая кинетика активной еды, режим обучения коэффициентов и решение об условиях GPL-3.0. Отдельный технический вопрос — объём долгосрочного SQLite-снимка.

## На физическом телефоне

- Сверить текущие значение, время и тренд с Follower в режимах «Авто», «Локальный Web Service» и ContentProvider. Проверить источник после остановки службы и восстановления связи.
- Проверить точность и дедупликацию истории после перезапуска, поведение в фоне, системное «Назад», установку и перенос резервной копии.
- Повторить профиль, LOW при пустом журнале, подтверждение фактов, дневник и экспорт. Технический результат хранить отдельно от клинического допуска.
