# JR-20261120-PHONE-FEEDBACK

Сверены оба архива. В 0.3.15-pilot подтверждено несовпадение роли текущего ContentProvider и HTTP-истории. Воспроизведены пустая вкладка измерений после записи, пустой список продуктов LOW и отсутствие маршрута Back. В новой ветке добавлены живой локальный Web Service, проверка источника и резервный канал. Профиль и подтверждённые события используют прежний SQLite. Настройки, продукты, коэффициенты и дневник остаются связаны с существующими модулями.

Версия 0.3.16-qa прошла основной нативный прогон Android 15. В расширенной проверке тест на API 34 искал устаревший заголовок дневника. API 36 выявил отказ возврата по системной кнопке. Версия 0.3.17-qa ограничивает OnBackInvokedCallback Android 16, обновляет критерий доступности дневника и сохраняет изменение типа еды в существующем черновике. Сбой API 36 повторён через системный ввод ADB.

Штатный API 31 в 0.3.16 остановился по тайм-ауту теста WebView после старта. Отдельный образ Google APIs не установился из-за лицензии пакета SDK. Эти прогоны не подтверждают совместимость. [Альтернативное испытание API 31](https://github.com/bmv2002qq-star/Glucopapa/actions/runs/44772854447)

Финальный код a1e8faef9603cc1a054e915062adb0c39d9552b7. Основной прогон на API 35 подтвердил подпись и SHA конкретного устанавливаемого APK. Повторная проверка на неизменных ресурсах APK прошла на API 31/34/35. Для неё откорректирован тест меню LOW, чтобы проверять справочный и фактический продукт. API 31 подтвердил касания, дерево доступности осталось ENV_BLOCKED. API 34 и 35 прошли четыре размера экрана, прерывание экспорта и краткий реальный soak. На API 35 прошли отмена и шесть периодов экспорта. Два запуска replay восстановили 25 920 записей после force-stop. [Расширенные прогоны](https://github.com/bmv2002qq-star/Glucopapa/actions/runs/44776452939)

В многофайловом Chromium подтверждены цвета и легенда спорта и болезни, 30 минут спорта и сохранение обоих интервалов. Совместимость резервных копий 0.3.15 → 0.3.17 проверена с синтетическими событиями. Два APK подписаны разными ключами. Личная библиотека проекта остаётся отдельным местом хранения.
