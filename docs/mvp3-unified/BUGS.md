# Открытые проблемы и закрытые дефекты

| ID | Статус | Причина или доказательство |
| --- | --- | --- |
| UNIFIED-DEMO-001 | FIXED | Переключатель тестового журнала и генератор перенесены в APK `fixture` с отдельным ID. |
| UNIFIED-FLAG-002 | FIXED | Миграция старого флага средней линии, один ключ, 16 сочетаний и синхронизация двух страниц. |
| UNIFIED-IA-003 | FIXED | Общая форма связывает РинФаст с едой одной транзакцией. Исторический IOB имеет отдельное происхождение. |
| XDRIP-PHONE-005 | NOT_TESTED | Нет замеров с телефона, версии Follower и согласованного доступа к цепочке GS1. |
| XDRIP-GAP-006 | PARTIAL | ContentProvider не возвращает историю за время остановки. Нативный HTTP из V1 потребует согласованной политики разрешений. |
| GFXDRIP-INPUT-007 | BLOCKED | Проверенный частный адаптер и оригинал v0.1.0 есть. Действующие правила фиксированного усвоения для runtime, сравнение с реальным xDrip+ и условия дистрибуции GPL не подтверждены. |
| FORECAST-FOOD-008 | BLOCKED | Для состава блюда нет утверждённого параметра плавной кинетики. Интервальный GFCOB не задаёт точечную траекторию. |
| CONSENSUS-REAL-009 | PARTIAL | В синтетике с полной историей две модели дают LEADER или COMPOSITE. Реального 24-часового сопоставимого ряда нет. Выбранная траектория читается калькуляторами в исследовательском блоке. Правила её применения к лечебному выводу отсутствуют. |
| LOWHIGH-MODEL-010 | BLOCKED | Исходные ограничения физиологии, болезни и активности сохраняются. Не подтверждён клинический паритет и безопасные лечебные рекомендации. |
| SQLITE-LIMIT-011 | PARTIAL | CAS, миграция, backup и сбой транзакции покрываются тестами. Верхняя граница большого JSON-снимка требует отдельной миграционной задачи. |
| UI-PARITY-012 | PARTIAL | 26 оригиналов байт-в-байт. Для GFMainScreen проверены ширины, жесты, факты и маршруты. Нативный перформанс и touch-паритет оцениваются отдельно. |
| QA-MATRIX-013 | PARTIAL | Полный автоматический Node прогон повторён. Старые 123 критерия включают устройство, недостающие правила и ручные сценарии. Для них нельзя проставить общий PASS. |
