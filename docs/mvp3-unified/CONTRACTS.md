# Изменённые контракты GFStorage

- Один активный GFStorage v0.5.12, прикладная схема 5, прежний SQLite schema 2. Снимок сохраняется CAS по ревизии, с проверкой SHA. Прежняя версия GFStorage v0.5.11 архивируется в исходном дереве и сохраняет исходную контрольную сумму.
- `graphPreferences.forecastVisibility.GFConsensus` управляет арифметической средней линией для отображения. На чтении legacy `showForecastMean` преобразуется в этот ключ, если уже сохранённое каноническое значение отсутствует. Остальные флаги сохраняются. Миграция применяется без записи при открытии. Копия v0.5.11 сохранена, обратное преобразование для ручного отката состоит в переносе значения `GFConsensus` в `showForecastMean` и удалении этого ключа из карты. Рабочий откат оставленной SQLite-схемы устройства отдельно не запускался.
- Независимые прогнозы архивируются как `glucopapa.research-forecast/2` по одному снимку. `glucopapa.consensus-selection/1` присоединяется к исследовательской записи GFConsensus v0.1.2 только при подтверждённых двух или трёх моделях и не менее 288 уникальных пятиминутных интервалов сопоставления на каждом горизонте 30/60/120. Порт проверяет исходные записи того же пакета. Режим AutoConsensus управляет исследовательским использованием, флажки отображения не влияют на архив и выбор. Новая ревизия входных фактов закрывает старые прогнозы.
- Читатели HIGH, LOW и GFMealCalc получают текущую траекторию из `graph` и показывают её в блоке расчёта. Исходные IOB, COB и активность не прибавляются к выбранной траектории снова. Ветки дозы и лечебной порции сохраняют действующие ограничения.
- `actionWriter.recordSessionInjection` записывает событие и ссылку на food session одной операцией при выборе связи в общей форме. Повтор идентификатора с теми же фактами идемпотентен. `glucopapa.preinjection-iob/1` хранит версию РинФаста, время, входную ревизию, подтверждённое окно и ссылки на уже имеющиеся быстрые инъекции. Левемир и записываемая сейчас инъекция не входят в список. При неполной истории объект отсутствует. Аналитика читает его ретроспективно и не применяет болезнь в ранжировании.
- CGM сохраняет действующий нативный контракт `cgmAdapter.ingestXDripObservation`. Локальные наблюдения xDrip+ недостаточны для автоматической смены статуса исследовательского качества. Подробности [аудита xDrip+](XDRIP_FOLLOWER_AUDIT.md).
