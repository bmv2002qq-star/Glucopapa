# JR-20261120-XDRIP-FOLLOWER

По дополнительному заданию найден нативный клиент GlucoPapa 0.26. Источник V1 использует локальный xDrip Web Service с историей, тогда как MVP3 читает последнее наблюдение из ContentProvider.

Проверены схема JSON старого сервиса, колонки ContentProvider, обработка режима Follower в опубликованной версии xDrip+, разрешения, конвертация, время, повторы и ветки ошибок V2. Добавлен синтетический Android-сценарий транзакции GFStorage, включая отказ от конфликтующего/будущего показания и восстановление. Активный клиент V2 сохранён.

Личный телефон и реальная цепочка Follower остаются `NOT_TESTED`. Причины и условия проверки зафиксированы в [отчёте](XDRIP_FOLLOWER_AUDIT.md) и [чек-листе](CL-XDRIP-FOLLOWER-20261120.md).
