# Аудит демонстрационных путей MVP3

| Место | Что найдено | Что проверено |
| --- | --- | --- |
| Оболочка `android-mvp3` | В исходном LOW переключатель режима, `seedDemo`, 24 тестовые точки и удаление браузерного журнала были доступны через настройки | Перенесены в `fixture`. В обычном APK кнопок и генератора нет. В Chromium запуск с прежней настройкой `demo` оставляет чистый локальный журнал. |
| Android SQLite и нативный мост | Раньше два ключа журнала были доступны через один APK | Обычная сборка отклоняет чтение тестового ключа и синтетический CGM. `fixture` имеет собственный package ID. Тестируется прежняя миграция SQLite без удаления строк. |
| `approved-library/`, старые HTML и модули | Превью, демо, старые GFStorage и ReplayLab находятся в источниках | Gradle пакует список из `LOAD_ORDER.txt` и `APK_FILES.txt`. Эти файлы остаются доступными для аудита исходников. В APK нет архивных HTML, тестовых скриптов и старых GFStorage. |
| `xdrip_chart.js` графика A | `fakeCgm` определяется и экспортируется внутри утверждённого файла | Защищённые байты прежние. Активный рендер получает только проверенные данные из GFStorage. Вызов генератора находится в исключённом архивном HTML. Старый суффикс «демо» в tooltip заменяется из достоверного источника в адаптере отображения. |
| HIGH, LOW и физиология | В коде есть явные ветви синтетического журнала и виртуальные профили | В обычной сборке журнал `local`. Синтетические ветви недостижимы через его UI, профиль для виртуальной физиологии отклоняется. Отсутствие входа идёт в статус, клинические гейты действуют. |
| Нативный xDrip+ и CGM | Один провайдер, явное включение, нет демонстрационного резервного потока | Пустая установка, провайдер отсутствует, неизвестные значения, конфликт времени и повтор проверяются отдельно. Подробности в [аудите Follower](XDRIP_FOLLOWER_AUDIT.md). |
| Корневой проект `app/src/main` | Старый APK V1 открывает браузерные демонстрации и имеет собственную схему SQLite | Он собирается отдельным Gradle-проектом. Этот код не попал в MVP3. Сохранён для истории и аудита старого xDrip+. |
| Сообщения iframe и WebView | Сопоставляются origin и конкретное окно. В архивном single-file есть ветвь `null` с `*` | В обычном APK используется фиксированный HTTPS-origin appassets и локальные пути. Отдельно проверены разрешённые маршруты, CSP и отклонение сообщений от другого iframe. |

По сканеру архива исследовано 168 файлов двух Android-проектов. В дереве 142 ресурса MVP3, из них 101 ресурс содержится в APK и совпал с исходниками по байтам. 26 защищённых файлов прошли сравнение SHA. Срабатывания сканера включают комментарии, плейсхолдеры форм, архивный код, предупреждения и ссылки на тестовые ветви. Вывод сканера и результаты динамических тестов приложены к сборке.

Полная приёмка каждого элемента 29 подсистем, системных сбоев WebView и внешнего CGM остаётся отражена в отдельных чек-листах.
