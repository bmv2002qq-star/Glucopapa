# GFxDrip v0.1.0

К ядру из архива привязан SHA-256 `47aa8b35d95316d00c85d070a43721598a1ccc2c5fabb877b444ed457616760b`. Архив содержит полный текст GPL-3.0 и ссылки на `Forecast.java`, `Treatments.java`, `BgGraphBuilder.java` и `Profile.java` xDrip+. Исходный JS-файл запускается локально из архива. В публичной ветке и APK его копии нет.

Локальный прогон исходника дал 44/44. Исходный стресс-сценарий прошёл 27 500 входов, содержит ожидаемые численные отказы и отдельно фиксирует слабые места валидации ядра. Обновлённый стенд формирует данные через GFStorage и передаёт в архивное ядро только подтверждённый РинФаст, фактическую еду, проверенное время и тестовые параметры конкретной модели. IOB и COB рассчитывает уже само ядро из одного набора фактов. Положительные наборы с 0/1/2 быстрыми инъекциями совпали с прямым запуском исходного ядра на тех же входах.

```bash
GLUCOPAPA_GFXDRIP_ENGINE=/path/to/gfxdrip_engine_v0.1.0.js \
  node --test qa/mvp3-unified/gfxdrip-input.test.cjs
```

GFxDrip не выдаёт третью линию в обычной сборке. Для включения нужен подтверждённый контракт скорости/задержки усвоения из фактической тарелки, сопоставление с работающим реальным xDrip+ и решение по условиям распространения GPL. Ядро частично переносит алгоритмы xDrip+, поэтому тест одинакового входа подтверждает соответствие адаптера архивному JS, а не паритет с Android xDrip+.
