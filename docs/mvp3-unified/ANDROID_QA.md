# Android и SQLite

Код `c091860497d3bae24129ca392c0517be22f653b1`. GitHub Actions собрал обычный APK с проверенным инвентарём ресурсов и отдельный `fixture`. Пакет `fixture` использовался для нарочно создаваемых событий пользователя. Обычный APK отдельно прошёл проверку чистого профиля и нативного пути CGM. Ниже результаты по синтетическим событиям в AVD с аппаратным ускорением.

| Android | Результат | Подтверждено |
| --- | --- | --- |
| 12 / API 31 | PASS_SCOPED | Нативный ввод Android открывает HIGH, LOW и дневник. Полный тест через дерево доступности WebView имеет статус ENV_BLOCKED. GFStorage, SQLite, отсечение дубля, восстановление, флаги и спорт прошли. |
| 14 / API 34 | PASS | Фактические касания, 320/390/428/1280, 86,2 с проверочного цикла, нехватка памяти в управляемом тесте, SQLite, системный диалог экспорта и восстановление после остановки. |
| 15 / API 35 | PASS_CORE | Фактические касания, проверка записи и отмены инъекции, конфликтов CGM, спорта, флага и восстановления. Расширенный прогон описан ниже. |
| 16 / API 36 | PASS | Фактические касания, 320/390/428/1280, 85,4 с проверочного цикла, сигнал нехватки памяти и возобновление, SQLite и восстановление. |

В обычном APK на каждом AVD проверены выход без CGM, отказ тестовому ключу, синтетический пакет штатного формата после проверки изоляции, сохранение исходных полей и одного события, отказ противоречивому и будущему пакету. `provider-restored.log` фиксирует чтение после `force-stop`. Контракт нативного MatrixCursor проверялся отдельно. Установленный на AVD xDrip+ Follower не участвовал в этих испытаниях.

SQLite instrumentation проверяет 1000 ревизий снимка, транзакцию с ошибкой, проверку целостности, миграцию и восстановление после прерывания. Обычные пользовательские сценарии проверялись отдельно по цепочке `fixture`, форма, GFStorage, SQLite, перезапуск и дневник. Полное выключение AVD с последующим стартом и двойной pinch через Android MotionEvent имеют статус `NOT_TESTED`. Жесты проверены в Chromium. Физический телефон и протяжённый натурный soak не выполнялись.

Расширенный Android 15 — **PASS после повторного запуска**. В первом прогоне элемент подтверждения оставался выключенным после ввода через accessibility. Повторный прогон прошёл. Проверены 85,0 с soak, навигация 320–1280, прерывания, 6 периодов JSONL через DocumentsUI и восстановление фактов LOW, спорта и флага.
