# Исходная точка единой сборки

Проверка 20 ноября 2026 года. Рабочая ветка `qa/mvp3-unified-20261120` создана от `7f3082c5cc6c256ddce90a0f5f4873a4dc5bd47a`. Это LOW с уже подключённым HIGH и аналитикой инъекций. Указанный в архиве HEAD ветки GFConsensus совпал с GitHub. У веток общий предок `6224d9454b708fee642fd27a007ce9e5e251a72f`; файлы оболочки и GFStorage разошлись. Изменения переносятся по контрактам, без слияния файлов целиком.

- Единый ZIP прошёл проверку CRC и 7 контрольных сумм комплектующих. Вложенный манифест Consensus содержит строку с хэшем самого себя. Эта строка расходится. Остальные перечисленные файлы, включая оба JS-кандидата, совпадают со своими контрольными суммами. Отличие JS-файлов от коммита GFConsensus ограничено строкой комментария.
- Утверждённые 26 ресурсов прошли контроль SHA-256. В источниках хранится журнал v0.1.1, в оболочке открыт трёхколоночный кандидат. Исходный график A сохранён.
- Рабочий Gradle-проект `android-mvp3` использует один GFStorage v0.5.11 со схемой 5 и один SQLiteOpenHelper. Корневой Gradle-проект собирает исторический отдельный APK с доступом в сеть и тестовым экраном. Он исследован как архивная ветвь проекта и исключён из сборки MVP3.
- В локальном режиме MVP3 раньше можно было переключиться в тестовый журнал, где работал генератор из 24 точек. Путь вынесен в `fixture` с отдельным идентификатором `com.glucopapa.shell.fixture`. Обычный APK отвергает синтетический CGM и тестовый ключ нативного хранилища. Прежние тестовые строки SQLite остаются недоступны обычному APK и сохранены при миграции схемы SQLite. Источники проверочных и архивных HTML остаются в репозитории.
- Обычный APK из Gradle 8.13 собран локально. Проверено 94 ресурса по явному списку загрузки и дистрибуции, подпись v2 и отсутствие ресурсов test-only. Node 1168/1168. Многофайловый Chromium прошёл сценарий LOW, 75 г, 14,925 г углеводов, ГИ 49, перезагрузка и разделение тестового и локального режимов. Локального `/dev/kvm` нет. Для Android проверку запускает GitHub Actions.

`ANDROID_DEVICE=NOT_TESTED`, `REAL_XDRIP=NOT_TESTED`, `CLINICAL=NOT_VALIDATED`.
