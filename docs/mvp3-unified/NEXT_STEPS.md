# Точка продолжения

1. Отдельная приёмка транспорта xDrip+ на фактически установленной версии Follower. Нужны свидетельства совпадения времени и значений, работы без сети между приложениями на одном телефоне, пропуска пакетов и восстановления. Условия в [аудите Follower](XDRIP_FOLLOWER_AUDIT.md).
2. Подтвердить источники и контракт кинетики конкретного блюда для GFForecast/GFCOB/LOW. Для GFxDrip есть отдельный адаптер проверки, остаются условия использования ядра и паритет с настоящим xDrip+. Без этих данных клинические ветки остаются закрытыми.
3. Получить не менее 24 часов сопоставимых прогнозов и наблюдений одного доказанного источника на каждой контрольной длительности. Использовать сериализованные контракты этого кандидата и отдельный журнал испытаний.
4. Проверить непокрытые пункты 123 критериев, крупные снимки SQLite, перезапуск после полного reboot AVD, touch-жесты Android и физический телефон с явным разрешением. Добавить к итогам точные версии, время и доказательства.
