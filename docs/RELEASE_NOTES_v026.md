# Заметки о версии 0.26

**Интерфейс**
- Кнопки «↓ Низкий сахар» и «↑ Высокий сахар» перенесены непосредственно под график; оформлены разными оттенками.
- Устаревшие плавающие действия убраны из области нижней навигации, доступ к тестам перенесён в раздел «Ещё».

**Расчётные модули**
- Автоанализ пяти завершённых суток в сценариях высокого и низкого сахара: СДИ, стартовые и ретроспективные ФЧИ и г/ЕД, предупреждения о качестве записей.
- Числовые проверки по фиктивному индивидуальному плану остаются демонстрационными, в реальном лечебном назначении не используются.

**Локальная Qwen**
- Контекст дневника сжат, добавлена диагностика библиотеки/файла GGUF/реального инференса и новый самотест.
- Настоящая генерация на физическом Android пока не проверена.

**Проверки**
- Проведён расширенный браузерный аудит, регрессионные JS-тесты и испытания Android-моста с имитацией.
- Полный APK и клиническая валидация пока отсутствуют.
