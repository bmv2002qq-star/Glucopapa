# План испытаний версии 0.26

## Проверки, выполненные до публикации в GitHub

Из отчёта браузерного аудита версии 0.26: 108 из 108 проверенных сценариев интерфейса; дополнительные проверки математических модулей, сохранения данных и имитации Android-моста. **Это проверки браузерного прототипа и исходного JavaScript, а не полное тестирование APK**.

Здесь повторно запущены восемь Node.js-тестов и `tools/check_local_ai.py` — см. `README.md`, а также workflow `CI source checks`.

## Что нужно проверить на установленном APK

1. Установка и первый запуск на ARM64.
2. Получение текущей глюкозы и истории из xDrip+ в реальных условиях, включая отсутствие разрешений и устаревшие данные.
3. Нажатия двух кнопок сразу под графиком и переход в медицинский анализ.
4. Сохранение/редактирование еды, инъекции, активности, категорий продуктов, расписания Левемира, истории исправлений.
5. Экспорт PDF и открытие файла на устройстве.
6. Импорт GGUF, наличие `libgluco_llm.so`, реальный самотест и ответ Qwen на контекст дневника.
7. Длительная работа приложения, выключение экрана, сеть отсутствует, недостаток памяти, повторный запуск.
8. Проверка отсутствия дублирования записей при повторном нажатии и сбоях.

## Что не верифицировано

- Воспроизводимость реальных показаний xDrip+ и работы Android Service.
- Сборка APK с `llama.cpp` (первая попытка GitHub Actions может выявить JNI/CMake несовместимость).
- Клиническая точность IOB, прогноза CGM и рекомендованных лечебных действий ребёнку.
- Точность чисел из пятидневного дневника для реального пациента.

Техническая успешность и медицинская допустимость — разные результаты. Все медицинские фикстуры в пакете искусственные.
