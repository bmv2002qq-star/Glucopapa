Расчёт · показать формулы макета

Доля усвоения сока: F(t) = 1 − (1 + t/20) × exp(−t/20). Углеводы сока: объём × 0,105 г; условный отклик: углеводы × 3/10 × F(t) ммоль/л.

Для теста добавлены упрощённые остаточные эффекты: IOB — отрицательная кривая, COB — положительная; тренд глюкозы с затуханием. Они не должны подменять реальные RinFastEngine, GFForecast/GFCOB и согласованный GFStorage, а двойной учёт уже проявившихся воздействий необходимо исключить при интеграции.

В тестовом HTML активность лишь отображается как вход; её влияние не моделируется. Итоговые численные значения не валидированы для клинического использования.

В рабочем приложении эти поля не показываются: CGM, IOB, COB и параметры ребёнка поступают через единый GFStorage.

В макете кнопка не записывает события: GFStorage не подключён.

Автономный макет для согласования компоновки и поведения калькулятора. Прогнозные значения иллюстративны и не предназначены для лечения. При реальной гипогликемии нужна незамедлительная помощь и повторный контроль по индивидуальному плану; глюкоза предпочтительнее сока. Экран не связан с CGM/xDrip или GFStorage.
