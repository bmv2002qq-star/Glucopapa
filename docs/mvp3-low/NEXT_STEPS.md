# Точка продолжения LOW

1. Подтвердить источник параметра усвоения для каждого фактически доступного продукта и правила его версионирования в едином GFStorage. Масса и ГИ сами по себе параметр не определяют.
2. Сверить на одинаковом снимке LOW и выбранную общую модель. Для GFCOB требуется отдельно утверждённое правило перехода от интервала COB к точечному эффекту. Прогнать численные эталоны повторно.
3. Отдельно согласовать любое включение количественного расчёта на реальном профиле, физический телефон и фактический xDrip. Утверждение нового экрана выполняется отдельно от технического тестирования.
4. Для записи факта LOW используется «Моя тарелка» и один actionWriter. Для продолжения зафиксирован checkpoint-low.json с исходным SHA, статусами сред и ссылкой на CI.
