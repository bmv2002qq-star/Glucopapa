Повторён архивный Node **39/39** для GFIA и **46/46** для GFMealCalc. Chromium подтвердил пять стадий и воспроизвёл потерю таймера после reload при сохранённом уколе. Этот браузерный сценарий использует тестовый результат GFIA. Отдельная регрессия исходного ядра использует оригинал из архива.

Владелец зафиксировал **FAIL_DEVICE** на 0.3.17. Web Service сообщает о будущем времени, ContentProvider не возвращает точек. Из ранее полученного примера сверены 13-разрядная метка UNIX и дата с явным смещением +0300. Они описывают один момент. Пример и телефонные скриншоты используются для локального анализа.

В V1 `GlucoBridge` обновляет снимок собственной базы после запроса `127.0.0.1:17580/sgv.json?count=288` при открытии и раз в минуту. В 0.3.17 запрос текущей точки `count=1` отбрасывал будущую точку без проверки остальных показаний. Способ из V1 воспроизведён с ограниченной пачкой, сравнением меток, явным исключением будущих точек и единым GFStorage.

GFSync v0.2.2 и исходное ядро v0.2.0 найдены в Android. Публичный репозиторий владельца, ветки и локальные файлы не содержат конфигурации рабочего Firebase или отдельного сервера. Старый V1 CloudDemo относится к другому внешнему сервису. Подключение трёх устройств требует существующей конфигурации и авторизации.
