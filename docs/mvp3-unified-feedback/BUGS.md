# Дефекты и открытые проверки

| ID | Статус | Доказательство и условие закрытия |
| --- | --- | --- |
| CGM-LIVE-P0 | BLOCKED_DEVICE | На 0.3.17 владелец наблюдал будущую метку Web Service и пустой ContentProvider. В 0.3.18 окно истории проверяется по текущим меткам Android. Живой Follower нужен для проверки часов, токенов доступа к провайдеру, восстановления и работы в фоне. |
| MEAL-STORAGE-PORT-P0 | FIXED_CODE | Результат исходного GFIA проходит порт GFStorage. Подтверждение сохраняет связанный снимок и один факт. Ревизия, версия сессии и происхождение проверяются при записи и чтении. |
| MEAL-TIMER-P0 | FIXED_BROWSER | Прогон с оригинальным ядром, одним уколом, reload, прошедшим временем и исправлением еды. Результат Android указан отдельно в протоколе. |
| MEAL-DOSE-P0 | BLOCKED | У GFMealCalc v0.1.4 отсутствует валидная индивидуальная рекомендация. Неизвестные значения отображаются явно. |
| NUTRITION-PER-MEAL | BLOCKED | Справочник содержит суточные диапазоны. Для сравнения одного блюда и балансировки требуется согласованная доля приёма. |
| COEF-AUTO | PARTIAL | Ручные записи, режимы и проверка пригодности истории доступны. Автоматический пересчёт действующего коэффициента требует подтверждённого источника и алгоритма. |
| SYNC-SERVER-P0 | BLOCKED | Исходный GFSync и три роли устройств найдены. Требуются конфигурация действующего сервера, авторизация и отдельные испытания на трёх телефонах. |
| GROWTH-REFERENCE | PARTIAL | ВОЗ ИМТ по возрасту открыт для парного измерения, рост и вес строятся из истории. Полных таблиц роста для других возрастов в исходниках нет. |
| ANDROID-INPUT | SEE_EVIDENCE | Нативный возврат, размеры экрана и состояние Accessibility отдельно в отчёте по версиям. |
| RELEASE-CERT | SEE_EVIDENCE | Перед обновлением сверить сертификаты. Формат копии 0.3.17 → 0.3.18 испытан на синтетике. |
| CLINICAL | NOT_VALIDATED | Техническая работоспособность исторического интервала и эмуляторные сценарии отделены от медицинской оценки. |
