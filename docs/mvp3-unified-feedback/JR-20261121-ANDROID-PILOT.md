21 ноября 2026 года. Технический пилот 0.3.18-qa. Ветка `qa/mvp3-unified-feedback-20261120`.

## Исходники и изменения

Рабочая версия APK `35f3a3cc2678faa9d7a11b91bc9e1fbbe464dff7`. Совпадающий runtime в повторном испытании `9dc4a539451cad09c3b0e98fd96c18aa2d520810`. Система Back использует Android OnBackInvokedCallback там, где он доступен. Переходы из питания ведут к одной форме GFMealCalc. Журнал событий и настройки используют прежнюю базу. История CGM из loopback и порт ContentProvider переходят в один GFStorage.

Результат исторического анализа записывается с фактом инъекции одной транзакцией. Пять карточек рабочего вида производны от утверждённого v0.3.0. Исходный GFInjectionAnalytics v0.2.1 и защищённые ресурсы совпали побайтно. [Сверка](DIFF_APPROVED.md)

## Доказательства

API 31 PASS, API 34 PASS, API 35 PASS, API 36 FAIL. Системный жест на API 36 имеет статус NOT_RUN. Установленный обычный APK Android 15 совпадает по SHA-256. Таймер и профиль восстановлены из SQLite. На Android 15 25 920 точек восстановились из SQLite после остановки приложения.

Во входном архиве обнаружена потеря таймера после reload. В предыдущем Android-прогоне на API 36 обнаружилась гонка, когда тест обращался к панели до полной загрузки WebView. Исправления и исходы отмечены в протоколе по коммитам. Проверены 10 архивных фактов еды, 864 шага архивного Replay, 10 000 стресс-сценариев калькуляторов и 30 синтетических профилей GFPhysio.

SHA-256 обычного APK `a5044e236fdaea2248d9f9ae6376a56eb4d47c051633d2ec64656bcd2c8d4f5f`. Сертификат APK отличается от 0.3.17-qa.
