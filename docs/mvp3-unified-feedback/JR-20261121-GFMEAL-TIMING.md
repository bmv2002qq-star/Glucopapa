# JR-20261121-GFMEAL-TIMING

GFMealCalc получает анализ по текущей тарелке из порта mealTiming. Порт mealTimingPublisher принимает результат оригинального GFInjectionAnalytics v0.2.1 по одной ревизии. По фактическому подтверждению actionWriter записывает инъекцию и снимок интервала через существующий CAS. Метки, выбранная доза, место, ревизия и версия тарелки должны совпасть. После перезапуска таймер читается из события. Число приходит из исторического анализа. При отсутствии интервала запись факта работает независимо.

Проверены исходное ядро, один подтверждённый укол, повтор, сбой записи, другая область укола, устаревшая ревизия, изменение факта и повреждённая связь в резервной копии. Интерфейс и испытание Android после принудительной остановки относятся к следующей контрольной точке.

На отдельном P0-коммите нативный Web Service и запись окна CGM прошли на API 35/36. Зафиксированы сбой Back API 36 и неполный прогон HIGH через штатный эмуляторный ввод API 35. [Прогон](https://github.com/bmv2002qq-star/Glucopapa/actions/runs/44803297458)
