Легенда: как тестировать

1. Измени углеводы еды и нажми «Сохранить изменения»; после «Подтвердить тарелку» открывается учебный расчёт.

2. Посмотри условные дозу и минуты. Кнопкой «Подставить учебный пример» заполни ручные поля (или введи свои тестовые числа).

3. «Учебный укол сделан» записывает отдельные решение и инъекцию. Таймер стартует по виртуальным часам.

4. Перематывай время кнопками +1 / +5 минут. Нажми «Начали есть» — фактическое время фиксируется независимо от таймера.

5. Выбери «Съел всё» или «Изменить съеденное», затем заверши еду. Перейти назад и исправить факт можно даже после завершения.

6. Попробуй сценарии 12,0 растёт, 5,2 падает и 3,6 гипо. Опасный вариант должен блокировать учебные подсказки.

7. После завершения нажми «Проиграть +2 часа CGM» — вымышленный эпизод попадёт в историю сравнения для нового теста.

8. Обнови страницу — при разрешённом браузером localStorage учебная база и история сохраняются. Кнопка «Сброс» удаляет только записи этой демоверсии.
