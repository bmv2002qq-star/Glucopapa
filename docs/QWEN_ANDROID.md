# Локальная Qwen: требования и диагностика

**Код**: `app/src/main/java/ru/family/glucodiary/LocalLlm.java`, `MainActivity.java`, `AiObservationContext.java` и `app/src/main/cpp/local_llm.cpp`.

- Нужен Android на архитектуре **arm64-v8a**, достаточно свободной памяти и место под GGUF.
- APK должен содержать нативную библиотеку `libgluco_llm.so`, создаваемую из кода C++/`llama.cpp`.
- Файл GGUF поставляется отдельно. Для первого теста предусмотрена небольшая instruct-модель Qwen в формате GGUF; она не включена в репозиторий.
- В **Ещё → Автономная нейросеть** импортируйте GGUF, нажмите **Проверить движок и модель** и **Запустить реальный самотест Qwen**. Считайте запуск подтверждённым только после непустого ответа, который действительно сгенерировала модель.
- Если самотест успешен, отдельно проверьте передачу контекста дневника и ответ в карточке **«2. Локальный Qwen / ML»** на экранах «Высокий сахар» и «Низкий сахар».

## Если не работает

| Симптом | Что проверить |
|---|---|
| `libgluco_llm.so` не загружается | ABI (arm64-v8a), результат JNI/CMake сборки, зависимости нативной библиотеки |
| GGUF не найден / повреждён | Правильность импорта и размер файла; первый заголовок `GGUF` |
| Ошибка токенизации или слишком длинного запроса | Сжатый контекст, ограничение токенов в C++ (`local_llm.cpp`) |
| Модель не загружается | RAM, свободное место, совместимость формата GGUF/версии llama.cpp |
| Самотест отвечает, а медицинская карточка — нет | Android JS-мост, обновление страницы, обработчик ответа и логи |

Для поиска ошибок с компьютера, где установлен ADB:

```bash
adb logcat -d | grep -Ei 'gluco_llm|llama|AndroidRuntime|UnsatisfiedLinkError'
```

Перед отправкой логов **уберите имена, значения личного CGM, данные дневника, ключи API и прочие чувствительные сведения**.

**Ограничения**: автоматизированные тесты с имитацией Android-моста и синтаксические проверки Java не доказывают успешную компиляцию JNI, импорт GGUF или фактическую генерацию ответа на телефоне. Эти действия должны быть проверены на физическом устройстве после сборки APK. Локальная Qwen не должна самостоятельно назначать детские дозировки.
