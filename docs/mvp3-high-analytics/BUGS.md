# Открытые вопросы

| ID | Состояние | Причина |
|---|---|---|
| HIGH-QA-001 | BLOCKED / CLINICAL_NOT_VALIDATED | На независимом виртуальном стенде воспроизводятся небезопасные модельные различия. Живой подбор дозы закрыт. |
| HIGH-QA-002 / HIGH-QA-010 | BLOCKED_POSTMEAL_POINT_MODEL | Исходные варианты HIGH автономного стенда и канонические пищевые модели различаются. Для плавной модели требуется правило выбора параметра по блюду. Для линейной требуется обоснованная проекция интервала в точечный прогноз. |
| HIGH-QA-011 | BLOCKED_CLINICAL_MODEL | При включённой болезни виден контекст и явный отказ расчёта. Согласованной инкрементальной формулы нет. |
| HIGH-XDRIP-DEVICE | NOT_TESTED | Для реального источника нужны измерения с разрешённого семейного телефона. В текущем provider качество для модели явно неизвестно. |
| IA-047-CONTEXT | PARTIAL | Для оценки нужна подтверждённая связь еды и укола с сохранённым IOB. Отдельный экран HIGH этой связи не создаёт. Если подтверждённого контекста нет, панель показывает причину NO_DATA. |
| IA-047-CLINICAL | NOT_VALIDATED | Стенд не определяет, как игнорирование болезни повлияет на качество статистики реальных пациентов. |
| IA-047-ISOLATION | FIXED | После переключения локального журнала на синтетический старые даты и результат оставались в открытой панели. При новом подключении GFStorage выбор и результат очищаются. |

Приёмка кандидатов и версии доказательств приведены в TEST_MATRIX.csv. Технические ошибки места, настроек HIGH, цели, CGM и отрицательных нутриентов проверены отдельно.
