# JR-20261120-HIGH-CL047-02 — подключение кандидатов

HIGH использует разметку утверждённого экрана, один GFStorage и общий RinfastEngine. В schema 5 добавлены опциональные, версионированные настройки HIGH. Фактическая инъекция идёт через actionWriter после подтверждения выполненного действия. Неподтверждённые дозы и фикстуры не становятся фактами.

GFInjectionAnalytics v0.2.1 используется в отдельной исторической панели. Фактические блюда и уколы проецируются из одной ревизии. Нужны подтверждённая связь и сохранённый IOB. При пропусках выдаётся NO_DATA, история не меняется.

Следующая проверка — Android WebView на API 31/34/35/36 и сопоставление результатов с исходным синтетическим стендом.
