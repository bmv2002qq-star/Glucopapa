# Точка продолжения HIGH и CL‑047

1. Разработать и согласовать один маршрут явного подтверждения связи фактической еды и фактического укола. Уточнить момент сохранения IOB и версионирование происхождения в существующем контексте инъекции. Старым фактам без доказанной связи оставлять NO_DATA.
2. Согласовать версионированное правило для параметра плавного усвоения по фактическому блюду или для точечной проекции диапазона GFCOB. До этого сценарий активной еды остаётся ограниченным, при отсутствии данных видна конкретная причина.
3. Продолжить проверку HIGH с независимыми эталонами активности и болезни. Дозовые сценарии относятся к синтетической оценке. Клиническая проверка отдельна.
4. Решение по лицензированию и адаптеру GFxDrip требуется для третьего прогноза. Реальный xDrip+ и физический телефон проверяются в отдельно согласованном этапе.
5. Для продолжения взять SHA из checkpoint-high-cl047.json и новые статусы из TEST_MATRIX.csv и CL040_RECHECK.csv. Проверку запускать по REPRODUCE.md.
