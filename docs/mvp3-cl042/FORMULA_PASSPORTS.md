# Паспорта исходных формул CL‑042.1

Числа и эталоны ниже относятся к вымышленным фикстурам. Полные SHA-256 и исходные пути приведены в [FORMULA_PROVENANCE_MATRIX.csv](FORMULA_PROVENANCE_MATRIX.csv). Физиологические параметры, допуски датчика и пригодность для лечения независимо не валидированы.

Исходники GFForecast, RinfastEngine, LevemirEngine и утверждённых HTML не менялись. Добавлена зависимость от RinfastEngine в адаптации IOB для AAPS, исходная автономная реализация осталась доступна для регрессии.
