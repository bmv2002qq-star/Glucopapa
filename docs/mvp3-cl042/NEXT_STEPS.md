# Точка продолжения CL‑042.1

1. Закрыть контракты CL042-TAU и CL042-LINEAR-POINT из FORMULA_GAPS.md. Повторить проверки фактических порций и общего графика на исходных формулах и независимых эталонах.
2. После решения по лицензии GFxDrip установить совместимость трёх прогнозов на одном снимке с единым РинФастом и выбранной моделью еды. Для сравнения с данными потребуется отдельный согласованный источник CGM.
3. Согласовать недостающие математические правила LOW, HIGH, расчёта под еду и изменения Левемира. Использовать исходные прототипы как эталоны в их установленных границах.
4. Пройти неполные критерии TEST_MATRIX.csv с указанными фикстурами. Реальный xDrip+ и медицинская пригодность требуют отдельных проверок.
