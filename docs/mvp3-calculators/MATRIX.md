# Три калькулятора и их зависимости

| Модуль | Версия и путь | Работа с GFStorage | Доказательства и граница |
|---|---|---|---|
| Низкий сахар | Защищённый v5, GF30Core, рабочий маршрут `approved-low` | Оболочка читает CGM, историю инъекций, еду, настройки и условия через существующие порты. Фактическая еда сохраняется только по подтверждению в существующем workflow. | Диагностика подключена. Ручные 30/40/60 мл проверены в архивной модели на синтетическом стенде. Полный рабочий прогноз с согласованным IOB/COB, выбором продукта и повторным спадом остаётся BLOCKED. |
| Высокий сахар | Защищённый v5, GF30Core, рабочий маршрут `approved-high` | Те же специализированные источники, отдельная форма фактической инъекции через `actionWriter`. | Синтетический расчёт отличил 0 ЕД, подтверждённую половину шага и отсутствие расчёта. В рабочем окне численный результат BLOCKED. |
| Инсулин под еду | GFNutrition v0.4.6 и GFMealCalc v0.1.4 | Тарелка из утверждённого iframe через `GFPlate.v1`; план и факт разделены в `mealSessions`; адаптер показывает выбранную запись. | Синтетическая арифметика и актуализация плана проверены. Полная корректировка количества и формула интервала не утверждены. Сравнение откликов по временам — только QA. |
| Диагностика | Новый `GFCalculationEvidence_v0.1.0.js` | Одна ревизия через порты `settings`, `cgmAdapter`, `graph`, `rinfast`, `levemir`, `research`, `journal`, `calculator`. | При смене ревизии подробности отбрасываются. Компонент показывает блокирующие причины отдельно от неопределённости. При ошибке базального порта прочие наблюдения доступны. |
| РинФаст | Утверждённое ядро v0.3.0, `GFInsulinEvidenceGate` | Подтверждённые инъекции, покрытие и время через `rinfast`. | Ноль только при полном заявленном покрытии и отсутствии действующих фактов. Учебная кривая GF30Core отличается и не подставляется в рабочий IOB. |
| COB / профиль еды | GFCOBResearch v0.1.1 и GFAutoCOBProfile v0.1.0 | Фактическая еда, история, ГИ/жиры/белки, метка заявления покрытия той же ревизии. | План не появляется в COB. Профиль использует ГИ и жиры, записывает белки; отдельного коэффициента усвоения белка нет. |
| Прогноз | GFForecast v0.1.2, отдельный стенд `research-forecast.cjs` | Каждая подтверждённая инъекция и еда поступают один раз через одну ревизию. COB показывается отдельно, повторное прибавление запрещено. | Модель еды с собственной константой не эквивалентна диапазону GFCOB. Достоверное совместное уравнение и валидация отсутствуют. |
| CGM | GFCgmEvidencePolicy v0.1.0, локальный xDrip+ из baseline | Время, источник, качество и свежесть из активного CGM-порта GFStorage. | Доступны наблюдения при годной свежести. Непереданное качество xDrip+ блокирует медицинский вывод. |
| Левемир, спорт, болезнь | Исходный движок и GFSettings, период из GFStorage | Хронология и выбранные параметры отдельно от IOB РинФаста; влияние не подставляется. | Чтение, границы интервалов и диагностика отказа проверены. Согласованного коэффициента воздействия на все три формулы нет. |
| GFPhysio | Комплект v0.1.2, 13 состояний, GFPhysioProfiles v0.2.0 | Изолированная симуляция подаёт синтетический ряд в отдельный временный GFStorage. | Отдельные наблюдения по исходному каналу состояния 13 и задержке транспорта. Числа не добавляются в реальный журнал. |
