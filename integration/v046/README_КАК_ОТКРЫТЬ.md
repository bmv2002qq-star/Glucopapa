# ГлюкоПапа — просмотр «Дневник + Продукты»
14 ноября 2026 г. · самостоятельная ветка, без изменений main

## Открыть
Скачайте ZIP этой ветки GitHub, распакуйте его и откройте в браузере:

`integration/v046/ГлюкоПапа_ДНЕВНИК_ПРОДУКТЫ_ПРОСМОТР.html`

Рядом, в той же папке, ОБЯЗАТЕЛЬНО должен оставаться файл:
`ГлюкоПапа_Питание_v0.4.6_ДЕМО.html`.

## Что сохранено
- «Продукты» открывают **оригинальный, неизменённый** HTML питания **v0.4.6**, каталог 1 958 карточек, оригинальная «Моя тарелка» и её закреплённая кнопка.
- Навигация между «Продукты» и другими разделами сохраняет существующий iframe в памяти страницы, а не пересоздаёт модуль при каждом переходе.
- «Дневник» взят из последнего доступного исходника с таблицей из 3 колонок: время, CGM со стрелкой тренда, детали еды или инъекции.
- В исходные расчётные формулы низкого/высокого сахара патч не вмешивается.

## Реальные ограничения
Это **интерфейсная интеграция**, а не окончательная рабочая GFShell v0.3.1. Из старой сборки GFShell v0.3.1 оригинальный архив недоступен в текущей среде; в основе просмотра использован доступный HTML v0.32 с ранее собранным табличным дневником. Полная связь GFNutrition → единый реальный GFStorage → GFJournal требует отдельной проверки и здесь **не реализована**. HTML питания использует собственный демонстрационный порт, а не рабочий профиль/CGM.

Демонстрационные медицинские цифры не предназначены для подбора доз или лечения ребёнка.

## Проверка
Проверяется структура исходников, наличие исходного модуля v0.4.6 в одной папке, оболочка с тремя графами дневника, изменение состояния показа вкладки «Продукты». Автоматический браузерный end-to-end тест этой новой интеграции пока не пройден; старый отчёт v0.4.6 относится только к независимому модулю питания.
