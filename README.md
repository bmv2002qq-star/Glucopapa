# GlucoPapa 0.26 — Android CGM & Food Diary (Research Prototype)

Экспериментальный Android-дневник глюкозы, еды, введённого инсулина, активности и исследовательского анализа CGM.

> **Медицинское предупреждение:** этот проект не является клинически валидированным медицинским устройством. Расчёты ФЧИ, IOB, углеводных коэффициентов, прогнозы и тестовые числовые примеры нельзя использовать для самостоятельного назначения инсулина или лечения гипогликемии ребёнка.

## Сборка APK

GitHub Actions запускает **Build GlucoPapa 0.26 APK** при коммитах в `main`. После успешного запуска ZIP-артефакт `GlucoPapa-v0.26-arm64-debug-APK` содержит `app-debug.apk`.

Java 17 · Gradle 8.10.2 · Android SDK 35 · NDK 27.2 · CMake 3.22.1 · ARM64.

Qwen GGUF нужно импортировать отдельно; GGUF не включена в APK. `llama.cpp` загружается workflow на закреплённом коммите.

Этот публичный репозиторий не содержит пациентских журналов, API-ключей, GGUF, keystore или пользовательской медицинской базы.
